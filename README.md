# Operational Business Intelligence Dashboard

## 📌 Project Overview
This project demonstrates the ability to translate raw stakeholder requirements into actionable business intelligence. Tasked with solving 8 specific operational questions provided in a project brief, I developed an interactive Power BI dashboard that transforms raw data into a clear, analytical narrative.

## 🛠️ Tech Stack & Skills Demonstrated
* **Power BI Desktop:** Data visualization and UI/UX design.
* **DAX (Data Analysis Expressions):** Engineered explicit measures to calculate custom KPIs and solve complex filtering requirements.
* **Data Modeling:** Established relational links between dimension and fact tables to ensure accurate cross-filtering.
* **Power Query:** Cleaned and transformed the raw operational data prior to loading.
